# 日本株トレードダッシュボード

## 目的
毎日の投資判断を「朝の仮説 → 寄り後の確認 → 売買 → 保有管理 → 引け後の検証 → 翌日改善」まで一貫して管理するためのスマホ優先ダッシュボードです。

## 推奨入口
- `hub.html` : 全機能への入口。スマホではここをブックマーク推奨

## ページ構成
- `index.html` : TODAY / DAY TRADE / SWING / PERFORMANCE / JOURNAL / SETTINGS
- `holdings.html` : 現在保有している銘柄の取得単価、現在値、含み損益、保有理由、利確・撤退条件
- `history.html` : 過去の約定履歴・売却履歴・日別サマリー
- `analytics.html` : 勝率、PF、平均利益・損失、期待値、利益集中度、銘柄別・日別・スタイル別分析
- `forecast.html` : 朝6:30時点の候補順位・上昇確率を固定し、実際の値動きと予想精度を検証
- `review.html` : R倍数、MAE、MFE、MFE捕捉率、ルール遵守を記録し、損切り・利益確定の質を検証
- `data/executions.json` : iSPEED画像から復元した約定番号0〜71の72約定
- `data/confirmed-trades.json` : 個別実現損益まで確認・マッピングできた取引
- `data/forecast-template.json` : 朝レポート取り込み用の将来互換テンプレート
- `data/review-template.json` : R/MAE/MFEレビュー用の将来互換テンプレート

## 損益データの優先順位
1. iSPEEDの確定実現損益
2. プロジェクト戦績台帳で確定済みの個別損益
3. 約定価格・約定数量から算出する参考値

8月の公式実現損益は **+42,500円** を基準値とします。約定価格から独自計算した粗損益を公式損益へ上書きしません。

勝率・PF・平均利益・平均損失などは、個別損益までマッピングできたサンプルについてのみ算出し、公式月間損益と混同しない設計にします。

## 毎日の運用
1. 06:30 朝戦略レポートを作成し、FORECAST に候補順位・予想確率・根拠を保存
2. TODAY で市場スタンス、米株、SOX、USD/JPY、日経先物、強弱業種を確認
3. DAY TRADE / SWING に候補を分けて管理
4. HOLDINGS で既存保有銘柄の材料・撤退条件を確認
5. 08:30前後に先物・為替・気配・追加IRの重要変化を確認
6. 09:00〜09:10にVWAP、高値、安値、出来高、板、同業他社を確認して買い/見送りを判断
7. 売買後はiSPEEDの確定実現損益を優先して記録
8. 引け後に FORECAST へ実際の値動きを反映し、予想の的中/外れを固定
9. TRADE REVIEW に初期損切り、初期利益目標、保有中高安を記録してR・MAE・MFEを算出
10. HISTORY / ANALYTICS で累積成績を確認し、翌日の候補選定へ反映

## デイトレとスイングの分離
- DAY TRADE: 当日のVWAP、寄り後高安、出来高、板、スプレッド、当日材料を重視
- SWING: 数日〜数週間のトレンド、材料期限、決算・イベント、業種資金流入、撤退条件を重視
- デイトレの含み損を理由にスイングへ変更しない

## R / MAE / MFE
- R倍数: 実現損益 ÷ エントリー時点の初期想定損失
- MAE: 保有中に最大でどこまで逆行したか
- MFE: 保有中に最大でどこまで順行したか
- MFE捕捉率: 実際に取れた利益 ÷ 保有中に最大で取れた利益

初期損切り価格は購入後に遠ざけた価格ではなく、エントリー時点で決めた価格を記録します。

## 予想精度
FORECASTでは寄り前に予想を固定し、後知恵を防ぎます。初期判定基準は以下です。
- デイトレ: 当日最大上昇率 +2%以上を「的中」
- スイング: 評価期間の終値騰落 +3%以上を「的中」

サンプルが蓄積したら、上昇確率60%の候補が実際に約60%当たっているかという「確率較正」も確認します。

## リスク管理
初期設定:
- 1日の実現損失上限: 10,000円
- 通常の1回損失目安: 5,000円
- 1銘柄の購入予算上限: 500,000円
- 基本売買単位: 100株
- 朝レポート: 06:30

SETTINGS から変更できます。

## 保存方式
現在のMVPはブラウザの localStorage に保存します。同じ端末・同じブラウザでは入力内容が残ります。

確定済みの履歴データはGitHub側のJSONにも保持し、ブラウザ内データだけに依存しない構成へ段階的に移行しています。

## 現在の制約
- 株価、為替、先物、ニュースは自動取得しない
- GitHub Pages上の静的Webアプリ
- 新規入力データの一部はブラウザ側に保存される
- 個別実現損益は全35件のうち、現在マッピング済みのサンプルだけで詳細分析する
- MAE/MFEは保有中の高値・安値を入力した取引のみ算出可能
