# 日本株トレードダッシュボード

## 目的
毎日の投資判断を「朝の仮説 → 寄り後の確認 → 売買 → 引け後の検証」まで一貫して管理するためのスマホ優先ダッシュボードです。

## 毎日の運用
1. 06:30 朝戦略レポートを確認
2. TODAY の「朝戦略を更新」から市場スタンス、米株、SOX、USD/JPY、日経先物、強弱業種を登録
3. DAY TRADE / SWING に候補を分けて登録
4. 08:30前後に先物・為替・気配・追加IRの重要変化を確認
5. 09:00〜09:10にデイトレ候補のVWAP、高値、安値、出来高、板、同業他社を確認して買い/見送りを判断
6. 売買後は「売買記録」にiSPEEDの確定実現損益を優先して入力
7. 引け後は JOURNAL に最も学びが大きかった1銘柄の振り返りを登録

## デイトレとスイングの分離
- DAY TRADE: 当日のVWAP、寄り後高安、出来高、板、スプレッド、当日材料を重視
- SWING: 数日〜数週間のトレンド、材料期限、決算・イベント、業種資金流入、撤退条件を重視
- デイトレの含み損を理由にスイングへ変更しない

## リスク管理
初期設定:
- 1日の実現損失上限: 10,000円
- 通常の1回損失目安: 5,000円
- 1銘柄の購入予算上限: 500,000円
- 基本売買単位: 100株
- 朝レポート: 06:30

SETTINGS から変更できます。

## 保存方式
現在のMVPはブラウザの localStorage に保存します。同じ端末・同じブラウザでは入力内容が残ります。

JSON出力 / JSON読込に対応しているため、バックアップや別端末への移行が可能です。

## 現在の制約
- 株価、為替、先物、ニュースは自動取得しない
- GitHub Pages上の静的Webアプリ
- 入力データはGitHub側には保存されず、ブラウザ側に保存される
