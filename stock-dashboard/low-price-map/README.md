# 300円以下 日本株・全銘柄マップ

日本市場の株価300円以下の上場株を、価格だけでなくセクター・業種・52週高安・流動性・時価総額・バリュエーションで横断比較するための静的ダッシュボードです。

## URL

GitHub Pages: `https://xxxkimkimkimxxx-prog.github.io/chatgpt/stock-dashboard/low-price-map/`

## 抽出定義

- 日本市場
- 一次上場（primary）
- 現在値が0円超300円以下
- 普通株・優先株・DR
- ETF、投資信託、Pre-IPOは除外

## データ

`update_data.py` が TradingView Stock Screener の Japan scanner から次の項目を取得し、`data.json` を生成します。

- 銘柄コード / 会社名
- 現在値 / 前日比
- 52週高値 / 52週安値
- 出来高 / 相対出来高
- 時価総額
- セクター / 業種
- PER / PBR / 配当利回り / EPS / ROE / D/E
- 1年騰落率

52週位置は `(現在値 - 52週安値) / (52週高値 - 52週安値)` で計算しています。

## 自動更新

GitHub Actions `update-low-price-stocks.yml` が平日15:40 JSTに更新します。手動実行も可能です。更新後は既存のGitHub Pages workflowで公開されます。

## 使い方

1. 業種マップで資金の偏りではなく、低位株の母集団構成を把握する。
2. 52週安値圏・出来高・時価総額で絞る。
3. 最大5銘柄を横並び比較する。
4. 個別深掘りで注意フラグを確認する。
5. 売買判断前に会社IR・TDnet・JPXの最新開示、当日チャート、VWAP、板、出来高を別途確認する。

## 注意

「株価が300円以下」は割安性を意味しません。株式併合前後、希薄化、継続企業リスク、低流動性、材料による急変などを必ず確認してください。本ダッシュボードはスクリーニング用途です。
