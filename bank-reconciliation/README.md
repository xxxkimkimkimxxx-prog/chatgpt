# 銀行入出金照合ツール Web版

Excel版 `銀行入出金照合ツール_v20.5.3.xlsx` を基準仕様として、GitHub Pages上で運用するブラウザ内処理型のWeb版です。

## 現在の基準

- Web版: `20.5.3-web.1`
- 社内日付基準: 転記日付
- 1対1探索範囲: 既定 ±5営業日
- 対象G/L勘定: 1111020001
- 通常組合せ探索: 最大30明細
- 詳細再探索: 最大60明細
- 社内同士取消: 有効
- 銀行同士取消: 実施しない
- 同月再取込: 差分更新・既存照合保持

## 実装済み

- 銀行RAW / 当社RAWのExcel・CSV読込
- 必要列の自動認識と手動マッピング
- 対象月・G/L勘定フィルタ
- 入出金区分の正規化（当社 S=入金 / H=出金）
- 完全6桁番号キー抽出
- 社内同士取消の自動消込
- 一意な1対1自動照合
- 1対1競合候補
- 1対多 / 多対1候補
- 候補競合の「複数候補有」判定
- 候補の折りたたみ表示
- 複数候補の一括照合と重複チェック
- 候補除外履歴
- 手動多対多照合（件数制限なし）
- 照合済みの複数選択解除
- 日付別・月合計の入出金比較
- 月次確定条件チェックとロック
- IndexedDBによる端末内月次DB保存
- 保存済み月の復元
- 対象月のみ / 全月の端末保存データ削除
- Excel出力
- 名寄せマスタ

## 更新方法

`main` ブランチの `bank-reconciliation/` 配下を更新すると、GitHub Pagesのワークフローにより同じ公開URLへ自動反映されます。修正履歴はGitのコミットとして残します。

## データ保護

RAWファイルはブラウザ内で解析します。RAW内容をGitHubへアップロードする処理はありません。月次DBは利用端末のIndexedDBに保存されます。

本番向けの安全化として、利用時の外部CDN読み込みを撤廃しています。SheetJS xlsx 0.18.5 はGitHub Actionsによる公開処理時に固定URLから取得し、SHA-512ハッシュを検証してからGitHub Pagesの同一サイト内へ配置します。利用者が銀行RAW・当社RAWを扱う実行時には外部CDNへアクセスしません。

アプリ本体にはContent Security Policyを設定し、`connect-src 'none'` により外部サーバーへの通信をブラウザ側で禁止しています。安全性の説明は `security.html` を参照してください。
