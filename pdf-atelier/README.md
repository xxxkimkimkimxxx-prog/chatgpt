# PDF Atelier

日本語PDFを、左のページ一覧・中央のプレビュー・右の入力パネルで編集するWebアプリです。初回起動時は架空データの3ページ請求書を表示します。

公開版：https://pdf-atelier-one.vercel.app/

## 主な機能

- ページ：結合、分割、回転、削除、並べ替え、複製、白紙追加、A4統一、トリミング
- 編集：Noto Sans JP／Noto Serif JP（標準・太字）を含む日本語テキスト追記・置換、画像、図形、矢印、マーカー、付箋、署名画像
- セキュリティ：墨消し、メタデータ・注釈・添付・リンク除去、AES-256パスワード保護
- 文書：ページ番号、ヘッダー、フッター、透かし、対話型フォーム、チェックボックス
- 認識・検査：ブラウザ内日本語／英語／縦書きOCR、手動／横書き自動傾き補正、文字差分、画像差分、個人情報候補抽出
- 出力：PDF、分割PDF、PNG、JPEG、TXT、Word（見た目優先／編集優先）、Excel（見た目＋編集／表抽出）、一括処理ZIP
- 操作支援：最大30操作のUndo/Redo、下書きファイル、任意のブラウザ内自動保存

## 必要環境

- Node.js 20以上
- Python 3.11以上
- 約350MBの空き容量（依存関係、Notoフォント、ブラウザOCR言語データを含む）

## セットアップ

```bash
npm install
python3 -m venv .venv
.venv/bin/python3 -m pip install -r requirements.txt
npm run dev -- --host 127.0.0.1 --port 4173
```

ブラウザで `http://127.0.0.1:4173/` を開きます。Windowsでは `.venv/bin/python3` を `.venv\Scripts\python.exe` に読み替えてください。Windowsで起動する場合は `vite.config.mjs` のPython実行ファイル選択を環境に合わせて調整する必要があります。

## 安全上の注意

- 公開版には利用者認証がありません。機密文書・個人情報を含む文書ではなく、検証用コピーを使用してください。
- ローカル開発サーバーをLANやインターネットへ直接公開しないでください。
- 重要書類は必ずコピーで作業し、書き出し後は別のPDFビューアでも文字、ページ順、墨消し、署名表示を確認してください。
- 墨消し前の情報はUndo履歴や元ファイルに残ります。共有するのは最終書き出しファイルだけにしてください。
- 個人情報候補抽出はメール、ハイフン付き電話番号、郵便番号のルール検出です。氏名、住所、画像内情報を網羅せず、安全性を保証しません。
- 署名機能は画像配置であり、電子証明書によるデジタル署名ではありません。署名済みPDFは改ざん検知を壊さないため編集を拒否します。
- Wordの見た目優先は各PDFページを画像として配置するため本文を直接編集できません。編集優先は文字位置を近似します。Excelは参照画像と編集セルを併設できますが、図、数式、マクロ、コメント等の完全再現は行いません。
- ブラウザOCRは元のPDF表示を保ったまま透明文字層を追加します。既に文字レイヤーがあるページへ実行すると検索文字が重複するため、確認警告を表示します。
- 横書き自動傾き補正と強圧縮はページを画像化するため、検索性やフォーム等の編集性が失われます。

## 処理方式

Viteの同一オリジンAPI（ローカル）またはVercel Python Function（公開版）でPDF処理を行います。OCR認識は自己ホストしたTesseract.jsと言語データを使いブラウザ内で実行し、認識座標だけをPDF文字層追加APIへ渡します。PDF本文はデータベースへ保存しません。書き出しデータはブラウザ内でダウンロード用Blobに変換します。

ファイル上限は1件25MB、文書150ページ、バッチは10文書・合計25MBです。サーバー処理は同時2件、通常120秒で打ち切ります。

## 配布とライセンス

主要依存関係には React、Vite、PyMuPDF、Pillow、Tesseract、python-docx、openpyxl 等があります。特にPyMuPDFはAGPLまたは商用ライセンスで提供されています。商用利用・社内配布・外部提供の前に、利用形態に合う各依存関係のライセンスを確認してください。本成果物は法務判断を代替しません。

公開版はVercel上で稼働します。OCR認識もブラウザ内で利用できます。外部提供を本格運用する場合は、認証、マルウェア検査、監視、強固な全体レート制限を追加してください。
