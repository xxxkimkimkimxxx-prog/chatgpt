# PDF Atelier - ブラウザー内処理版

PDFを外部の文書処理APIへ送らず、利用者のブラウザー内で編集するWebアプリです。左にページ一覧、中央にプレビュー、右に文字入力・出力を配置します。

## 現在利用できる機能

- PDFを開く、表示、複数PDFの結合
- ページの回転、削除、複製、並べ替え、白紙追加
- Noto Sans JPで日本語文字を画像として追加し、PDFへ保存
- PNG／JPEG画像や手書き署名画像を、指定範囲へ端末内で配置
- 範囲指定によるマーカー
- 日本語・英語OCRの端末内文字抽出（一度に5ページまで）
- 抽出文字を使った文字中心のWord／Excel出力
- ページ画像を配置する見た目優先のWord／Excel出力
- 選択ページだけを別PDFとして保存
- 直前10世代までのメモリー内Undo

## 未提供・制限中

- 検索可能な日本語OCR文字層：精度検証が終わるまで無効
- 既存文字の自在な置換、完全な墨消し、暗号化、フォーム編集、証明書付き電子署名：未実装
- 「画像・署名を配置」は署名画像の貼り付けであり、本人性や改ざん防止を証明する電子署名ではない
- 回転済みページへの文字・マーカー追加：座標検証が終わるまで拒否
- Word／Excelの配置完全一致：保証しない。見た目優先は画像なので本文を直接編集できない
- 40MB超のPDF、OCRの6ページ以上一括処理：iPhone安定性のため拒否

## プライバシー設計

- アクティブな画面コードには文書APIへの送信処理がありません。
- Render/Vercelの `/api/*` はリクエスト本文を読む前に拒否します。
- PDF、入力文字、OCR結果はブラウザーのメモリー内で処理します。
- 自動保存、クラウド同期、アクセス解析、外部AI APIを使用しません。
- 初回表示時にはJavaScript、フォント、OCR言語データ等を配信元から取得します。これはPDF本文の送信ではありません。

公開済みURLがこのソースへ更新されたことは未確認です。公開確認が完了するまで既存の公開版へ機密文書を読み込ませないでください。

## 開発

Node.js 22推奨。

```bash
npm install
npm run dev -- --host 127.0.0.1
npm test
npm run build:web
```

公開用コンテナにはPython PDFエンジンを含めず、生成済み静的ファイルとAPI拒否サーバーだけを格納します。

## ライセンス上の注意

主要依存関係はReact、Vite、PDF.js、pdf-lib、Tesseract.js、docx、JSZip、Notoフォントです。旧Pythonエンジンのコードは移行検証用にリポジトリへ残っていますが、現在の画面・公開コンテナからは使用しません。本格配布前に各依存関係のライセンスを確認してください。
