# PDF Atelier 検証報告

実施日：2026-09-20

## 結果

| 区分 | 結果 | 内容 |
| --- | --- | --- |
| PDFエンジン／公開API | 合格 59/59 | ページ操作、4方向座標、Noto 4書体、OCR文字層、墨消し、暗号化、フォーム、Office変換、画像差分、バッチ、Vercelアダプター等 |
| HTTP往復 | 合格 1/1 | サンプル取得、編集、検査、拒否系、出力、ダウンロードバイト完全一致 |
| 静的配信 | 合格 4/4 | 静的ファイル、SPAフォールバック、API誤配信防止、成果物構成 |
| 本番ビルド | 合格 | Viteビルド、Sitesパッケージ生成、Vercel本番デプロイ |
| ブラウザ操作 | 合格（下記例外あり） | 読込、文字プレビュー、失敗時非更新、確定、Undo、回転、複製、削除、モーダル、Esc、保存リンク |
| デザインQA | 合格 | P2の縦領域不足を修正後、P0/P1/P2なし |

## 自動検証した重要項目

- 3ページのサンプルPDFと請求額の整合
- 0／90／180／270度での文字配置
- 全ページ削除、範囲外座標、不正色、不正PDF、不正Base64の拒否
- 文字置換失敗時に元PDFを変更しない原子性
- 墨消し後に対象文字、画像画素、メタデータ、注釈、添付、リンク、オブジェクトストリームから秘密文字列が消えること
- AES-256暗号化で誤パスワードを拒否し、正しいパスワードで復号できること
- Noto Sans JP／Serif JPの標準・太字を埋め込み、日本語・英数・補助漢字を抽出できること
- OCR透明文字層が0／90／180／270度で検索でき、OCR前後の表示画素が一致すること
- AcroFormの値とAppearance Stream、チェックON/OFF
- Wordの見た目優先／編集優先、Excelの見た目＋編集／表抽出、選択ページ限定、画像格納、数式注入防止
- 文字差分では見えない図形差が画像差分で検出されること
- 個人情報候補3種、バッチ全件成功／1件失敗時の非出力、自動傾き推定
- HTTP保存ファイルが送信したPDFとバイト単位で一致すること

## ブラウザで確認した操作

- 日本語入力が中央プレビューへ即時反映
- 長い文字が枠に収まらない場合、エラー表示してUndo履歴を増やさない
- 文字サイズ調整後の置換確定と、確定後のPDF文字レイヤー再検出
- Undoで元の日本語へ復元
- 右90度回転とUndo、ページ複製、削除
- 「その他の機能」に高度機能4種が表示されること
- Escでモーダルを閉じ、フォーカスを呼び出し元へ戻すこと
- 生成済みPDFをファイル選択から再読込し、3ページと文字レイヤーを復元
- PDF出力後にブラウザ内Blobの保存リンクが生成されること
- アプリ由来のブラウザコンソール警告・エラーが0件であること

## 残存する検証上の制約

- クラウド検証ブラウザがプログラム起点のダウンロード完了イベントを返さないため、UI上では保存リンク生成までを確認しました。HTTP統合テストでは、同じ保存経路のレスポンス、Content-Type、Content-Disposition、PDFバイト完全一致を確認済みです。
- クラウド検証ブラウザのビューポートは1363×936固定で、実ブラウザによる760px未満の画像比較は実行できませんでした。モバイル用CSS、320px最小幅、縦積みレイアウトは実装済みですが、実機確認を推奨します。
- OCR、個人情報候補、傾き推定、表抽出、編集優先Office再配置はヒューリスティックです。多様な実文書での精度保証ではありません。
- Notoの空白はPDF抽出器によって通常空白またはNBSPとして返る場合があります。表示と日本語文字列は検証済みです。
- 悪意あるPDFのファジング、長時間負荷試験、複数OS／複数PDFビューア互換試験、アクセシビリティ専門監査は未実施です。

## 判定

ローカル版とVercel公開版の主要フローは合格です。公開版は認証なしの検証用途であり、機密文書を扱う本格運用には認証、マルウェア対策、監視、強固な全体レート制限と追加負荷試験が必要です。
